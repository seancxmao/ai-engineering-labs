# AI Engienering Labs

A collection of focused, hands-on experiments for building foundations, resolving technical gaps, and exploring emerging technologies.

通过范围明确、目标具体的动手实验，补齐基础能力、解决技术盲点、探索新兴技术。它有三个主要职能。

1. Foundations & Prerequisites
    基础知识与前置技术。为主 repo 补齐必要的知识和工具能力。既包括入门内容，也包括那些技术上很深入、但问题范围狭窄的局部研究。例如：CMake 的构建机制、Python Packaging、CUDA 内存模型、某个底层 API 的行为。

2. Technical Investigations
    技术盲点与定向探索。在研究主 repo 的过程中，遇到一个具体问题，就围绕这个问题开展独立实验。把探索路径、验证过程和最终结论记录下来，避免反复摸索，也避免主 repo 被过多支线细节打乱。例如：追踪一个 Python 扩展模块如何被编译和加载，或者验证 vLLM 某个接口的具体行为。

3. Emerging Technologies
    前沿技术与新兴方向探索。对新出现的技术、热门概念和前沿项目进行小规模实践，先验证其原理、用途和实际价值，再决定是否值得投入更多时间。例如：试用新发布的推理框架、实验性编译技术，或者探索尚未纳入核心技术路线的新工具。
